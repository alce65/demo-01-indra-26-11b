# Demo 01

Esto es una demo de un repositorio de Git para un curso.

Es importante utilizar el fichero `.gitignore` para evitar subir archivos que no son necesarios al repositorio, como archivos de log, temporales, binarios, etc.

Ejemplo de contenido del archivo `.gitignore`:

```
# Ignorar archivos de log
*.log
# Ignorar archivos temporales
*.tmp
```

En el primer commit se creó 
- un archivo de texto llamado `readme.md` con el contenido que estás leyendo.
- un archivo de texto llamado `.gitignore` con el contenido ignorado popr git
- un archivo de texto llamado `.editorconfig` con el contenido de configuración del editor


Hemos visto:

- git init
- git add
- git commit
